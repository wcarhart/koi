## Supercharge your scripts.

Koi is a small, sourceable argument parser for Bash. Start with your existing script logic and functions and use as little or as much of koi as you'd like. Each function defines an interface of arguments and koi handles parsing and loading the argument values into variables for you to use.

<!-- koi:panel -->

## From one command to a whole toolbox.

Koi supports building Bash-native CLIs right out of the box. You can register commands each with their own parser, so you can nest subcommands as far as `$FUNCNEST` will go. Koi will handle subcommand routing, argument parsing, and autogenerated help menus for you.

<!-- koi:panel -->

## Use shell-like interfaces within your scripts.

You can also use koi within your script without any CLI argument parsing. Since registering argument interfaces via koi is function-based, you can use koi in your script-internal functions to use shell-like `-f`, `--flag`, and `--option VALUE` arguments to make your scripts easier to maintain and use.

<!-- koi:panel -->

## Intuitive help menus, for free.

Don't waste extra time building and maintaining help menus for your functions or CLI. Koi builds deterministic help menus on the fly based on your argument registration, including support for flags, argument grouping, subcommands, and much more. Support for `-h`, `--help` and the `help` subcommand comes out of the box.

<!-- koi:panel -->

## Works on Mac and Linux.

Koi is written 100% in Bash and supports any system running Bash 5.2 or later. It's available on all mainstream installers, such as Homebrew and `apt`, but you can also download the single `koi` source file from GitHub and vendor it yourself.
